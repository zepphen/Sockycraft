# Changelog

All notable changes to the Sockycraft modpack. Newest version first.

## v1.1.1 — 2026-09-28

### Added
- Xaero's World Map, XaeroPlus, Xaero's Maps: Multiplayer+ (shared maps), Xaero's Waystones compatibility
- Ping Wheel and Ping to Map
- JEI, SmartSort, Chat Heads, Simple Voice Chat Group Player Names
- AstikorCarts Redux
- Kotlin for Forge (library required by Xaero's Maps: Multiplayer+)

### Removed
- Forgified Fabric API — nothing in the pack needs it anymore
- Timber — its license doesn't allow redistributing the jar

### Changed
- Pack is now named "Sockycraft" in the CurseForge launcher
- Personal client settings no longer ship with the pack (voice chat mic/speaker selection, JEI world bookmarks). Voice chat will ask you to pick your mic on first launch.

### Notes
- Tried and dropped Nifty Carts via Sinytra Connector. Connector broke Cosy Critters, and Nifty Carts needs Fabric-only config code that Connector can't provide on 1.21.1. AstikorCarts Redux is the NeoForge-native replacement.
